AF-SDR 1.12.1 / Windows x64 配布版
================================

【動作条件】
・Windows x64、.NET 9 Windows Desktop Runtime (x64)。SDKは実行には不要です。
  https://dotnet.microsoft.com/ja-jp/download/dotnet/9.0
・Microsoft Visual C++ v14 再頒布可能パッケージ (x64)。rtlsdr.dllが使用します。
  https://learn.microsoft.com/ja-jp/cpp/windows/latest-supported-vc-redist
・RTL-SDRで受信する場合は、対応ドングル・アンテナ・動作するUSBドライバー。

ドングル、アンテナ、デバイスドライバーの提供・導入・設定・動作保証は
本配布の対象外です。利用者自身の責任で用意してください。
SDR#等で同じ機器が正常に受信できることを確認済みの環境を前提とします。
本ZIPはドライバーをインストール・変更しません。
IQ WAVファイルの再生にはドングルは不要です。

【起動】
1. ZIPを任意のフォルダーへすべて展開します（ZIP内から直接起動しない）。
2. 上記ランタイムを準備し、AF-SDR.exeを起動します。
   EXEだけを移動せず、同階層のDLL・JSONも一緒に保持してください。
3. RTL-SDR入力では他のSDRソフトによるデバイス使用を終了し、接続します。
   中心周波数は 78.4M、500k、78400000 等で入力できます。
4. ファイル入力では「IQ WAVを開く…」でファイルを選び、「再生」を押します。
   IQ用2チャンネルWAVを使用してください。通常の音楽WAVはIQ信号ではありません。

【主な操作】
スペクトラムとウォーターフォール、FM放送モノラル音声、デジタル信号表示、
IQ WAV再生に対応します。音声はFM受信をONにしたとき既定の音声機器へ出力します。
デジタル表示のSymbol Rateと手動周波数補正は桁クリック＋ホイール／スピンで
即時調整できます。変調形式・RRC等の解析条件は「適用」で反映します。
I/Q（同期なし）の軌跡は整数8 SPSの表示用IQの経路です。
デジタル表示は信号観察用であり、データ復号機能はありません。

【設定と更新】
設定保存先: %LOCALAPPDATA%\AF-SDR\settings.json
ウィンドウ位置・サイズや各種設定を復元します。受信・再生・音声を起動時に
自動開始しません。配布ZIPに開発者の個人設定や録音データは含めていません。
更新時はアプリを終了し、新しい版を別フォルダーへ展開してください。
設定は同じWindowsユーザー内で共有されます。必要なら設定ファイルをバックアップ
してください。削除時は配布フォルダーを削除します。設定ファイルは残ります。
